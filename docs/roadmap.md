# Build roadmap

## Milestone 1: frontend preview and foundation

- [x] Repository structure and local Next.js landing page
- [x] Interactive frontend previews for brand import, creative, campaign flow, approvals, WhatsApp booking, and analytics
- [ ] FastAPI endpoints and frontend integration
- [ ] Clerk token verification and organization membership authorization
- [ ] Workspaces, brand briefs, campaign drafts, approval decisions, and audit records
- [ ] Tenant and approval tests
- [ ] Production database migrations and PostgreSQL tenant safeguards

## Milestone 2: first complete booked-lead loop

- Website crawler and versioned brand extraction
- AI provider gateway with validated output schemas and run/cost records
- Campaign and creative generation
- Landing-page publishing, forms, UTM/click ID capture, and lead records
- Booking flow and basic attribution report

## Milestone 3: conversion channels

- WhatsApp opt-in, templates, human handoff, and reminders
- Google Business Profile, Google Calendar, Meta Ads, and Google Ads integrations
- Durable workflows, retries, idempotent webhooks, and daily budget caps

## Milestone 4: agency operations

- Multi-client switcher, billing, reporting, revenue attribution, and optimization suggestions
- Export/deletion workflows and expanded audit controls
